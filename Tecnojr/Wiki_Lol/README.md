# Wiki_Lol

Projeto desenvolvido como **etapa do processo seletivo de trainee da TecnoJr**, para entrar na empresa júnior.

Site informativo sobre League of Legends, feito em HTML, CSS e JavaScript puro. Mostra campeões, skins e habilidades, consumindo a API de dados do jogo (Data Dragon) com `fetch`.

Para abrir, use `projeto_final/index.html` no navegador.
