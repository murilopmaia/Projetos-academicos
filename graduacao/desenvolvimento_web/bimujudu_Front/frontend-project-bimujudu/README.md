
># Atividade 1
* Modelo de página principal com cabeçalho, rodapé, menu e conteúdo.
    * Feito no index, contato e sobre

* Página de listagem de itens, com opções de editar, excluir ou visualizar detalhes do item. Pode ser um layout de tabela de cards ou outra.
    * Feito na parte de serviços, utlizando para excluir, editar, visualizar e adicionar o prompt

* Página de formulário, com validação de obrigatório para tudo e, no mínimo, os campos: text, text[email], text[fone], password, select, radiobutton, checkbox e textarea.
    * Feito na parte de formulário

># Atividade 2
* Foi utilizado no backend nodeJs com Sqlite apenas para fins de facilidade de desenvolvimento 
    * Para rodar usar o comando ***npx nodemon server.js***
* O front foi utilizado o react.js com vite
    * Para rodar usar o comando ***npm run dev***
